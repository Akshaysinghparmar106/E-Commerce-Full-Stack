# E-Commerce Full Stack Web Application

A full-stack e-commerce web application built using React.js, Java Spring Boot, and MySQL. This project provides product browsing, shopping cart, user registration and login, and checkout functionality.

## 🚀 Features

- Product listing
- Add to Cart
- Increase and decrease product quantity
- Cart total calculation
- User Registration and Login
- Password encryption using BCrypt
- Checkout functionality
- Order placement
- My Orders
- REST API integration
- MySQL database integration

## 🛠️ Tech Stack

**Frontend**
- React.js
- JavaScript
- HTML5
- CSS3

**Backend**
- Java 17
- Spring Boot
- Spring Data JPA
- REST API

**Database**
- MySQL 8

**Tools**
- Git
- GitHub
- Maven
- VS Code

## 📂 Project Structure

- frontend – React application
- backend – Spring Boot REST API
- MySQL – Database for storing products, users and orders

## ▶️ How to Run the Project

### Frontend

```bash
cd frontend
npm install
npm start
```

Frontend runs at:

http://localhost:3000

### Backend

```bash
cd backend
./mvnw spring-boot:run
```

Backend runs at:

http://localhost:8080

### Database

Create a MySQL database named:

`ecommerce_db`

Configure your database username and password in your local Spring Boot configuration.
